Bienvenido a CineVerse

CineVerse es una plataforma web interactiva desarrollada para la exploración, consulta y administración completa de títulos cinematográficos.

Este sistema consume una API REST centralizada construida en Laravel y ofrece una interfaz gráfica ágil, moderna y totalmente responsiva desarrollada en Angular. A través de este panel podrás explorar el listado completo de producciones, consultar el detalle técnico de cada obra y gestionar la información de forma dinámica.
